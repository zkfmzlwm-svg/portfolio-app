# 스위칭 국면별 목표비중 근거 분석

`REGIME_TARGETS`(index.html)의 공격/중립/방어 프리셋을 데이터로 재산정한 분석입니다.

## 재현
```bash
./fetch.sh            # FRED·DBnomics·Yahoo 원자료 → data/
python3 sig.py        # ISM 대용지표 검증
python3 analysis.py   # (모듈) 국면·수익률 데이터셋
python3 bt.py         # 워크포워드 최적화 백테스트
python3 rules.py      # 고정 틸트 규칙 비교 (최종안 근거)
```

## 데이터 (월간, KRW 환산, 2002-09 ~ 2026-09, 285개월)
| 자산군 | 대용 | 비고 |
|---|---|---|
| 국내주식 | KOSPI(^KS11) + 배당 1.8%/년 | |
| 해외주식 | SPY 수정주가 × USD/KRW | |
| 채권 | IEF(미 7-10년물) × USD/KRW | 앱이 채권을 USD로 보관 |
| 금 | GC=F(~2004) → GLD × USD/KRW | |
| 코인 | BTC-USD × USD/KRW | 2014-10~ |

국면 신호는 앱과 같은 방식입니다. 소매판매 YoY(FRED `MRTSSM44X72USS`)와 ISM 제조업 가격지수 각각의 MA3가 2회 연속 오르면 강세, 둘 다 하락이면 약세, 그 밖에는 중립입니다.
- ISM 가격지수의 장기 무료 데이터가 없어서 2021년 이전은 **PPI(PPIACO) 3개월 변화율**로 대체했습니다. 실제 ISM과 국면 일치율은 79%이고, 강세↔약세가 뒤바뀐 경우는 0건입니다.
- 발표 시차를 반영해 데이터월 t의 신호는 t+2월 수익률에 적용합니다.
- 현재 시점 데이터를 쓰므로 소매판매 수정치 반영에 따른 미래정보 편향이 일부 남아 있습니다.

# 고정 비중 최적화 (국면 무관 단일 비중)

```bash
python3 static.py [코인할인]  # 그리드(5%p, 4170조합) + 12개월 블록 부트스트랩 리샘플 최적 + 워크포워드
python3 robust.py             # 위험기반(ERC·최소분산·역변동성) 워크포워드 + 하위기간 maximin
python3 candidates.py         # 후보별 하위기간·스트레스·리밸런싱 주기 비교
```
Sharpe는 원화 무위험수익률(한국 3개월 금리, FRED `IR3TIB01KRM156N`) 차감 기준입니다.

## 최적화 결과는 기간에 따라 크게 흔들림
| 방법 | 국내/해외/채권/금/코인 |
|---|---|
| 2014~ 단순 최대샤프 (과최적화) | 15/40/0/35/10 |
| 2014~ 리샘플 최적 | 13/38/2/39/9 |
| 하위기간 3개 maximin 상위 2% 평균 | 36/11/3/33/16 |
| 워크포워드 연도별 최적 | 2010년 36/9/10/45/0 → 2026년 10/38/3/39/10 |

- 매년 과거 최적 비중으로 갈아타는 워크포워드는 2010~2026 아웃오브샘플 Sharpe 0.83이었습니다. 현행 고정 비중(1.15)보다 낮습니다. 과거 수익률로 최적화하면 지난 승자를 쫓게 됩니다.
- 여러 방법에서 공통으로 나온 결과만 근거로 씁니다.
  - **채권(미국채 원화환산)은 0~10%.** 원화 투자자에게는 달러 자산 자체가 위기 헤지 역할을 하기 때문입니다.
  - **금은 25~40%.**
  - **코인은 5~20%.**
  - **국내·해외 주식 배분은 방법마다 달라 불안정합니다.**

## 후보 비교 (월 리밸런싱)
| | 현행 25/25/20/20/10 | **추천 20/30/10/30/10** | 25/25/5/35/10 |
|---|---|---|---|
| 전체 2003-2026 Sharpe / MDD | 1.04 / −15.2 | **1.08 / −13.2** | 1.08 / −13.1 |
| 2003-2009 Sharpe | 0.76 | 0.81 | 0.90 |
| 2010-2017 Sharpe | 1.17 | 1.12 | 1.03 |
| 2018-2026 Sharpe | 1.18 | 1.28 | 1.26 |
| 금 약세 2011.9-2015.12 Sharpe | 0.47 | **0.30** | 0.08 |
| 금융위기 2007.11-2009.2 CAGR | 14.0 | 15.2 | 14.3 |

금 비중 35%안은 금 약세기에 Sharpe가 0.08까지 무너졌습니다. 그래서 금을 30%로 두고 달러 자산 비중을 높인 20/30/10/30/10을 추천안으로 정했습니다.

## 리밸런싱 주기 (2014-10~, 매매비용 0.3%, 추천안 기준)
| 월 | 분기 | 연 | ±5%p 밴드 | ±10%p 밴드 |
|---|---|---|---|---|
| Sharpe 1.42 · MDD −13.3 | **1.46 · −13.9** | 1.28 · −23.1 | 1.40 · −12.8 | 1.39 · −15.1 |
