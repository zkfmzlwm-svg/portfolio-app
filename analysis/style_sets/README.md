# 국면별 국내·해외 주식 ETF 세트 (홍춘욱 듀얼 스위칭)

앱 기본 프리셋(홍춘욱 원전략) 스타일 목표를 ETF로 채운 세트입니다. 비중은 각 주식 버킷 **안의** 비중(%)입니다.

```bash
../regime_weights/fetch.sh && ../style_tilt/fetch.sh && ./fetch.sh
python3 sets.py      # 세트 산출 + 백테스트 → sets.json
```

## 구성 규칙
- 세 국면 모두 같은 ETF를 쓰고 비중만 바꿉니다. 국면이 바뀔 때 매매를 줄이기 위해서입니다.
- 핵심 ETF(KODEX 200 / VOO)는 40%로 고정합니다. 위성 ETF는 5%~상한(국내 30%, 해외 35%)입니다.
- 5%p 격자를 전부 탐색해, 목표 비중과의 최대 오차가 가장 작은 조합을 고릅니다.
- 핵심 비중과 상한은 목표 오차 5%p 이내인 조합 가운데 국면 전환 회전율이 가장 낮은 값으로 정했습니다.
- 스타일 비중은 앱과 같은 방식으로 셉니다(태그 기준, '지수'는 가치/성장 50:50).
- **앱에서는 아래 태그 그대로 붙여야** 스타일 목표 카드가 같은 값을 보여줍니다. 특히 KODEX 200은 `대형주`만 붙입니다.
- 국내 소형 가치형 ETF는 시가총액 100억 안팎으로 거래가 거의 없어 쓰지 않았습니다. 국내 소형은 코스닥150(성장 성격)으로 채웁니다.

## 백테스트 (월 리밸런싱, 비용 제외, 현지통화, 국면 신호 2개월 시차)

- 국면 스위칭의 효과는 국내 연 −0.29%p(t −0.58), 해외 연 +0.10%p(t +0.49)입니다. 둘 다 통계적으로 의미 있는 차이가 아닙니다. 국면 전환 매매 회전율은 연 64%입니다.
- **국내 세트는 KODEX 200 단독보다 연 약 3%p 낮았습니다.** 2012년 이후 국내 수익은 반도체(KODEX 반도체 연 15.2%)와 금융·고배당(연 8~10%)에서 나왔습니다. 반면 자동차(1.4%), 소프트웨어(3.3%), 코스닥150(1.7%, 2015~)은 부진했습니다. 스타일 분산을 위해 위성에 이 섹터들을 넣으면 시장 대비 반도체 비중이 줄어듭니다.
- 해외 세트는 S&P500과 거의 같은 성과입니다.
