# 국면별 국내·해외 주식 ETF 세트 (홍춘욱 2단계, v7.3)

앱 기본 프리셋(홍춘욱 2단계)의 스타일 목표를 ETF로 채운 세트입니다. 비중은 각 주식 버킷 **안의** 비중(%)입니다.

```bash
../regime_weights/fetch.sh && ../style_tilt/fetch.sh && ./fetch.sh
python3 sets.py      # 세트 산출 + 백테스트 → sets.json
```

## 구성 규칙
- 국면은 🟢 상승 신호(두 지표 MA3 모두 3개월 연속 ↑)와 🔶 하락/중립 두 가지입니다.
- 두 국면 모두 같은 ETF를 쓰고 비중만 바꿉니다. 각 ETF는 5~40%이고, 5%p 격자를 전부 탐색해 목표 오차가 가장 작은 조합을 고릅니다.
- 국내 축은 앱과 같은 **태그 점수** 방식입니다. 종목 태그 중 경기민감(수출·가치·대형) 태그 비율만큼 경기민감으로 셉니다.
  - 예: 반도체[대형·수출·성장] = 2/3 경기민감, 소프트웨어[대형·내수·성장] = 1/3 경기민감.
- 해외는 대형 100%입니다(소형주 ETF 없음). 가치/성장 집계에서 '지수'는 50:50입니다.
- 앱에서도 아래 태그 그대로 붙여야 스타일 목표 카드가 같은 값을 보여줍니다.

## 백테스트 (월 리밸런싱, 비용 제외, 현지통화, 국면 신호 2개월 시차)
데이터: 2026-11-20 수집, 수익률 2026-10까지. 최신 국면(2026-09 지표 → 2026-11 적용)은 🔶 하락/중립입니다.

상장 전 구간은 대용 지수로 채웠습니다: 코스닥150 → 코스닥지수+배당 0.6%, PLUS 고배당주 → KODEX 은행, VOO → IVV, VTV → IWD, VUG → IWF.

|---|---|---|---|---|
| 🇰🇷 CAGR / Sharpe / MDD | 2012-05~2026-10 | 6.41% / 0.316 / −37.5% | 7.65% / 0.372 / −35.1% | KODEX 200 10.39% / 0.415 / −42.5% |
| 🌏 CAGR / Sharpe / MDD | 2000-08~2026-10 | 8.21% / 0.527 / −50.0% | 8.23% / 0.540 / −50.7% | S&P500 8.08% / 0.535 / −50.8% |

- 국면 스위칭의 효과는 국내 연 −1.22%p(t −1.06), 해외 연 +0.03%p(t +0.12)입니다. 국면 전환 매매 회전율은 국내 연 105%, 해외 연 40%입니다.
- **국내 하락/중립 세트는 코스닥150이 40%입니다.** 이 국면이 전체 기간의 85%라 사실상 상시 비중입니다. 코스닥150은 2015년 이후 연 0.8%로 가장 부진했습니다. 그래서 v7.2 3단계 세트(연 7.46%)보다 낮습니다.
  - 방어·성장 쪽을 코스닥 대신 내수 대형(소프트웨어 등)으로 채우면 이 손실이 줄어듭니다. 다만 태그 점수상 내수 대형도 1/3은 경기민감으로 세지기 때문에, 그만큼 방어·성장 비중을 채우기가 어렵습니다.
- 2012년 이후 국내 수익은 반도체(KODEX 반도체 연 13.7%)와 금융·고배당(연 8.5~9.8%)에서 나왔습니다. 자동차(1.3%), 소프트웨어(3.5%), 코스닥150(0.8%, 2015~)은 부진했습니다.
- 해외 세트는 S&P500과 거의 같은 성과입니다.
