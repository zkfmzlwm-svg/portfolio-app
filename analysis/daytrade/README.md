# 단타(변동성 돌파) — 국내 주식·ETF 검증

단타 탭(v5.6)의 근거 분석입니다. 국내 ETF 12종과 개별주 70종목의 일봉(2014-07~2026-10, 네이버 수정주가)으로 Larry Williams 변동성 돌파를 검증했습니다. 코인 5분봉 단타는 비교용으로 함께 넣었습니다.

```bash
python3 fetch.py          # 국내 일봉 → data/kr (약 1분)
python3 fetch.py --upbit  # + 업비트 일봉·5분봉 → data/upbit (5분봉은 마켓당 약 10분)
python3 report.py         # 국내 표 1)~6) 재현 (약 5분)
python3 crypto.py         # 코인 비교
```

## 규칙과 비용
- **목표가** = 당일 시가 + k × 전일(고가−저가)을 호가단위로 올림. 장중 고가가 목표가에 닿으면 매수합니다.
- **체결가** = 목표가 + 1호가. 청산은 **당일 종가** 또는 **다음날 시가**(둘 다 동시호가 체결이라 스프레드 없음)로 비교했습니다.
- **필터**: 없음 / 시가 > 전일까지 MA5 / MA20.
- **비용**: 수수료 편도 0.015%. 개별주는 매도 증권거래세 0.20%(2026년 세율, 코스피는 농특세 포함)를 전 기간에 적용했습니다. 국내 ETF는 거래세가 없습니다.
- **포트폴리오**: 종목마다 자금을 1/N씩 나눠, 신호가 없는 날은 현금으로 둡니다.
- 개별주는 지금 남아 있는 대형주와 앱 보유·워치리스트 종목이라 생존편향이 있습니다.

## 1) 당일 청산 vs 다음날 시가 청산 (전체 기간)
| 대상 | 청산 | CAGR 범위 (k 0.3~0.7 × 필터 3종) | 거래당 총수익 | 거래당 순수익 |
|---|---|---|---|---|
| ETF 6종 (레버리지 포함, 비과세 가정) | 당일 종가 | −0.2 ~ +3.1% | +0.03 ~ +0.10% | +0.00 ~ +0.07% |
| ETF 6종 | **다음날 시가** | **+7.9 ~ +16.2%** | +0.14 ~ +0.25% | +0.11 ~ +0.22% |
| 개별주 70종목 (거래세 0.2%) | 당일 종가 | −41 ~ −7% | −0.12 ~ +0.02% | −0.35 ~ −0.21% |
| 개별주 70종목 | 다음날 시가 | −27 ~ +1.6% | +0.03 ~ +0.28% | −0.20 ~ +0.05% |

- **장중에는 돌파 후 오히려 밀렸습니다.** 개별주는 돌파한 날 종가까지 들고 가면 총수익(비용 전)부터 마이너스입니다. 수익은 다음날 시가까지의 밤사이 구간에서 나왔습니다.
- 그래서 앱 기본값은 '다음날 시가 청산'입니다. 엄밀히는 당일 단타가 아니라 1박 단기매매입니다.

## 2) 학습(2014-07~2019) → 검증(2020-01~2026-10)
36개 설정(k 0.3~0.8 × 필터 3 × 청산 2)을 학습 구간에서 고르고 검증 구간에서 확인했습니다.

| 대상 | 학습 최적 | 학습 Sharpe | 검증 Sharpe / CAGR / MDD | 학습·검증 순위상관 | 검증 Sharpe>0 | 검증 보유 CAGR / Sharpe / MDD |
|---|---|---|---|---|---|---|
| ETF 6종 | k 0.8, 없음, 다음날 | 2.04 | 0.90 / +9.8% / −20% | 0.95 | 81% | +20.8% / 0.67 / −52% |
| **ETF 4종 (비레버리지)** | k 0.8, 없음, 다음날 | 2.80 | **1.45 / +13.6% / −13%** | 0.95 | **100%** | +18.9% / 0.70 / −40% |
| 개별주 70 | k 0.8, MA5, 다음날 | 0.09 | 1.09 / +3.8% / −11% | 0.96 | 25% | +27.3% / 1.09 / −40% |

- 설정 간 순위는 두 구간에서 거의 같았습니다(순위상관 0.95). 다만 Sharpe 수준은 학습 구간보다 절반 가까이 낮아졌습니다.
- 개별주는 검증 구간 설정의 75%가 Sharpe 0 이하였습니다. 보유(+27.3%)를 이긴 설정은 없습니다.

## 3) ETF 4종 설정별 (검증 2020~, 다음날 시가) + 수동 주문 슬리피지
대상은 KODEX 200·KODEX 코스닥150·KODEX 반도체·KODEX 2차전지산업입니다. 모두 국내 주식형이라 거래세와 매매차익이 비과세입니다. '+0.1%'·'+0.2%' 열은 목표가보다 그만큼 비싸게 샀을 때입니다.

- **앱 기본값은 k 0.7·필터 없음입니다.** Sharpe가 가장 높고, 슬리피지 +0.1%에서도 CAGR이 가장 많이 남습니다.
- **가장 큰 위험은 체결 지연입니다.** 목표가보다 0.1% 비싸게 사면 CAGR이 절반, 0.2%면 0입니다. 그래서 앱은 지정가를 기본으로 하고, 장중에 직접 본 돌파의 '감지가'를 기록해 실제 슬리피지를 따로 잽니다.

- **일봉 변동성 돌파**(k 0.5, MA5)는 2017~21 BTC +66%, 2022~26 BTC +5%(보유 +15%)로 최근 성과가 크게 줄었습니다.
