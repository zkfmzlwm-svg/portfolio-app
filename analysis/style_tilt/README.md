# 스위칭 국면별 국내·해외 주식 내부 스타일 비중 분석

국면 신호는 `../regime_weights`와 같습니다. 소매판매 YoY와 ISM 가격지수의 MA3를 쓰고, 2021년 이전 ISM은 PPI로 대체하며, 발표 시차 2개월을 반영합니다. 2026년 ISM은 앱 자동수집값으로 보완했습니다.

```bash
../regime_weights/fetch.sh && ./fetch.sh
python3 style.py      # 국면별 연환산 스프레드 + Welch t-test + 전/후반 부호
python3 tilt_bt.py    # 국면 라벨 순환이동 검정 + 버킷 내부 틸트 백테스트
```

- 5% 수준에서 유의한 스프레드는 없습니다. 방향이 전·후반 모두 일관된 축은 **KR 대형/소형**, **US 가치/성장**, **US 대형/소형** 세 가지입니다.
- **수출/내수는 국면에 따른 차이가 없습니다.** 수출 섹터가 모든 국면에서 연 4% 안팎으로 앞섰는데, 이는 구조적 차이로 봐야 합니다.
- 홍춘욱 전략의 "약세 → 소형주"는 미국에서 반대로 나왔습니다. 약세 국면에서는 대형주가 소형주보다 연 4% 앞섰습니다. 반면 "약세 → 성장주"는 미국 데이터와 일치합니다.

## 앱 목표비중 산정 (`python3 weights.py`)
- 기준 비중: 5%p 그리드에서 Sharpe가 최대인 고정 비중을 전체기간·전반기·후반기 각각 구한 뒤 평균했습니다.
- 국면 틸트: 기준 비중 ±15%p 안에서 국면별 비중을 탐색했습니다. 전반기와 후반기 모두 Sharpe가 개선되는 조합 중 개선폭이 가장 큰 것을 골랐습니다.
- 전체기간 Sharpe 개선이 0.01 미만인 축은 국면과 관계없이 고정합니다. 분산을 위해 모든 비중은 5~95%로 제한합니다.

| 축 (A : B) | 강세 | 중립 | 약세 | Sharpe 고정 → 틸트 |
|---|---|---|---|---|
| 국내 대형 : 소형 | 95 : 5 | 90 : 10 | 75 : 25 | 0.623 → 0.649 |
| 국내 수출 : 내수 | 65 : 35 | 65 : 35 | 65 : 35 | 0.439 → 0.442 (틸트 미채택) |
| 해외 가치 : 성장 | 75 : 25 | 60 : 40 | 45 : 55 | 0.580 → 0.597 |
| 해외 대형 : 소형 | 80 : 20 | 65 : 35 | 80 : 20 | 0.567 → 0.584 |

각 칸은 `A : B` 비중(%)이고 합은 100입니다.

전반기·후반기 최적 비중이 0%와 100% 사이에서 크게 흔들려서, 실제로 쓸 수 있는 정밀도는 ±10%p 안팎입니다. 앱에서는 이 표를 권장값으로 쓰고, 축별로 직접 바꿀 수 있습니다(`portfolio.styleTargets`).

## 구판(`weights.py`) 문제
1. **코너해 평균**: 두 자산 Sharpe 최대화는 0% 또는 100%가 나옵니다. 전체·전반·후반 코너해를 평균한 값(예: 미국 대형:소형 100/0/100 → 65)을 기준비중으로 써서, 미국 소형주가 35%(시가총액 ~7%의 5배)로 잡혔습니다.
2. **배당 편향**: KODEX200은 배당 포함 수정주가, 코스닥(^KQ11)은 가격지수라 대형주 쪽에 연 ~1.1%p 유리했습니다. KODEX200 수정−종가 차이 1.73%/년, KODEX 코스닥150은 0.62%/년 → 코스닥에 0.6%/년을 더했습니다.
3. **인샘플 선택**: 국면 틸트를 같은 표본에서 고르고 평가했습니다.
