# 스위칭 국면별 국내·해외 주식 내부 스타일 비중 분석

국면 신호는 `../regime_weights`와 같습니다. 소매판매 YoY와 ISM 가격지수의 MA3를 쓰고, 2021년 이전 ISM은 PPI로 대체하며, 발표 시차 2개월을 반영합니다. 2026년 ISM은 앱 자동수집값으로 보완했습니다.

```bash
../regime_weights/fetch.sh && ./fetch.sh
python3 style.py      # 국면별 연환산 스프레드 + Welch t-test + 전/후반 부호
python3 tilt_bt.py    # 국면 라벨 순환이동 검정 + 버킷 내부 틸트 백테스트
```

- 5% 수준에서 유의한 스프레드는 없습니다. 방향이 전·후반 모두 일관된 축은 **KR 대형/소형**, **US 가치/성장**, **US 대형/소형** 세 가지입니다.
- **수출/내수는 국면에 따른 차이가 없습니다.** 수출 섹터가 모든 국면에서 연 4% 안팎으로 앞섰는데, 이는 구조적 차이로 봐야 합니다.
- 홍춘욱 전략의 "약세 → 소형주"는 미국에서 반대로 나왔습니다. 약세 국면에서는 대형주가 소형주보다 연 4% 앞섰습니다. 반면 "약세 → 성장주"는 미국 데이터와 일치합니다.
