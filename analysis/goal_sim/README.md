# 🎯 10억 목표 도달 확률 — 몬테카를로

10년 뒤 10억원에 닿을 확률이 가장 높은 자산군 비중을 찾고, 월 적립·기간·절세·스위칭 레버의 효과를 비교한 분석입니다. 앱 v6.4의 고정 목표비중(`FIXED_TARGETS` 30/20/5/25/20)과 리밸런싱 탭 🎯 카드의 근거입니다.

```bash
../regime_weights/fetch.sh
python3 sim.py    # 1) 비중 그리드 1,300조합 × 기대수익 가정 4개 (약 8분)
python3 pick.py   # 2) 후보 정밀 비교(4,000경로) + 과거 MDD  3) 레버별 효과 · 50% 확률에 필요한 월 적립
V0=1e8 python3 pick.py   # 시작 자산 1억원 기준
REL=0.25 python3 pick.py # v6.4 표 재현(반기 + 목표 금액 ±25% 수시)
```

> **v6.5부터 리밸런싱은 반기 1회만**(수시 없음, `../rebal_cycle/timing.py`)이고 스크립트 기본값도 같습니다. 아래 1)~3) 표는 v6.4 당시 규칙(반기 + ±25% 수시, `REL=0.25`) 결과입니다. 반기 단독으로 바꾸면 확률이 모두 오르고(채택안·시작 1억 59 → 64%, 월 400만 84%, 50%에 필요한 월 적립 204 → 176만원), 비중 순위는 같습니다(코인 20 상위권, 30/20/5/25/20은 최상위와 1~2%p 차이).

## 방법
- **경로**: 2014-10~2026-09 원화 월수익률(국내 KODEX 200, 해외 SPY, 채권 IEF, 금 GLD, 코인 BTC — `../regime_weights`)을 **12개월 블록 부트스트랩**으로 이어 붙입니다. 변동성·상관·급락 구간은 과거 그대로입니다.
- **평균은 가정으로 바꿈**: 과거 연수익률(국내 11 · 해외 15 · 채권 3 · 금 13 · 코인 65%)을 그대로 쓰면 지나치게 낙관적입니다. 로그수익률 평균을 빼고 아래 연 기하 기대수익으로 다시 맞췄습니다.

  | 가정 | 국내 | 해외 | 채권 | 금 | 코인 |
  |---|---|---|---|---|---|
  | base | 7 | 8 | 3.5 | 5 | **15** |
  | coin0 / coin8 / coin30 | 같음 | | | | 0 / 8 / 30 |

- **운영 규칙은 앱과 동일**: 매월 적립금은 부족 자산군에만 부족액 비례로 넣고, 6·12월 반기 리밸런싱(v6.4 표는 목표 금액 ±25% 수시 포함), 매매비용 0.3%입니다. 세금·인플레이션은 뺐습니다.
- **시작 자산**: 이전 답변(기준안 중앙 6.22억)에 맞춰 보정하면 0.03억, 즉 거의 0원에서 시작하는 셈입니다. 앱은 실제 총자산으로 계산합니다.

## 1) 비중 탐색 (`sim.py`)
국내 0~40, 해외 20~60, 채권 0~20, 금 0~35, 코인 0~20%를 5%p 단위로 탐색했습니다(1,300조합). 코인 상한 20%는 `regime_weights` 고정 비중 분석과 같습니다.
- **상위권은 모두 코인 20% · 채권 0%** 입니다. 주식·금 배분(35/20/25, 30/25/25, 30/30/20, 35/25/20 …)은 확률 차이가 1%p 안팎으로 오차 범위 안입니다.
- 코인 기대수익을 0%로 낮춰도 순위는 같습니다. 코인 변동성(연 65%)을 반기마다 되파는 리밸런싱 효과 때문입니다.

- 확률만 보면 채권 0%가 최상위입니다. 다만 채권을 아예 빼는 건 과하다는 사용자 판단에 따라 **채권 5%를 남기고 해외에서 5%p를 옮긴 30/20/5/25/20**을 채택했습니다. 확률 차이(22.1 → 21.0%)는 오차 범위 안이고, 과거 MDD는 같습니다(−21.8 vs −21.9%).
- 이전 비중(20/30/10/25/15)에서 바뀌는 폭은 국내 +10, 해외 −10, 채권 −5, 코인 +5%p입니다.
- **하위 10%는 거의 그대로**(4.06 → 4.04억)입니다. 상단만 넓어집니다. 대신 하락장 낙폭(MDD)은 −17.6% → −21.9%로 커집니다.
- 코인을 20% 넘게 올리면 확률은 더 오르지만 MDD가 −26~−29%이고, 코인 하나가 포트폴리오 위험의 대부분을 차지합니다(`../rebal_cycle/gold_crypto.py`: 15%에서 이미 61%). 그래서 상한 20%를 유지했습니다.

- P(≥10억) 50%에 필요한 월 적립: 기준안 **402만원** → 채택안 **362만원**.
- 시작 자산이 1억원이면 채택안 월 250만으로 P 59% · 중앙 11.3억 · 하위10% 6.0억(기준안 49% · 10.0억 · 6.0억), 50%에 필요한 월 적립은 204만원입니다.
- '스위칭 성공 +3%p'는 가정입니다. 스타일 틸트 백테스트(`../style_tilt`)의 개선폭은 Sharpe +0.02~0.03으로 이보다 작을 수 있습니다.
- 절세: 연금저축 600 + IRP 300 = 연 900만원 세액공제(총급여 5,500만원 이하 16.5%, 그 외 13.2%). ISA 만기 자금을 60일 안에 연금계좌로 옮기면 옮긴 금액의 10%(최대 300만원)를 추가로 공제받습니다.

## 앱 반영 (v6.4)
- `FIXED_TARGETS` = 30/20/5/25/20(10억 목표형), 이전 비중은 `STABLE_TARGETS`(안정형)로 남김. 기존 사용자는 1회 교체(`goalTargetsV1`).
- 리밸런싱 탭 🎯 카드: 같은 몬테카를로를 JS로 실행(1,000경로, 같은 월수익률 표 `GOAL_L`)해 **실제 총자산·월 적립·남은 기간·절세 설정**으로 확률·중앙·하위10%와 레버 표를 계산합니다. JS와 Python 결과는 `temp/smoke_goal.js`에서 대조합니다(±4%p).

투자 참고용 추정치이며 기대수익 가정에 크게 좌우됩니다. 세액공제 한도·공제율은 소득 구간에 따라 확인이 필요합니다.
