# 보유종목 캡처 → 앱 붙여넣기 텍스트 변환

증권사/코인 거래소 앱의 보유종목 화면 캡처 이미지를 읽어, 포트폴리오 앱의
`parseSnapshotText()` 파서가 그대로 인식할 수 있는 일반 텍스트로 변환한다.

## 절차

1. 첨부된 이미지(1장 이상)를 각각 읽고, 보유종목이 나열된 행을 모두 찾는다.
   순위 번호, 탭 이름, 총 평가금액 등 종목이 아닌 행은 무시한다.
2. 각 종목 행에서 다음 4가지 값을 추출한다.
   - **종목명**: 화면에 표시된 그대로 (예: `삼천당제약`, `1Q 은액티브`, `비트코인`).
     괄호 안 부가 설명(거래소명 등)은 제외하되 종목명 자체의 숫자/한글은 그대로 둔다.
   - **수량**
   - **현재가** (현재가/평가단가 컬럼)
   - **평균단가** (매입단가/평단 컬럼)
3. 한 줄에 한 종목씩, 다음 순서·형식으로만 출력한다 (그 외 컬럼은 출력하지 않음):

   ```
   종목명 수량 현재가 평균단가
   ```

   - 공백으로 구분한다.
   - 숫자는 콤마(,)나 `원` 단위 없이 순수 숫자로 쓴다 (예: `170,400원` → `170400`).
   - 수익률(%)·평가금액 컬럼은 출력하지 않는다.
   - 화면에 보이는 순서를 그대로 유지한다.
4. 정수 보유분과 소수(단수) 보유분이 화면에 별도 행으로 나뉘어 있는 종목(배당 재투자 등)은,
   본 행 다음 줄에 아래 형식으로 추가한다 — 이 줄의 현재가·평균단가는 무시되므로 본 행과
   같은 값을 채우면 된다:

   ```
   소수 추가수량 현재가 평균단가
   ```

5. 여러 장의 캡처(국내/해외/코인 탭 등)가 첨부됐다면 모든 종목을 하나의 텍스트 블록으로
   합쳐서 출력한다. 종목의 자산군(국내/해외/채권/금/코인)은 앱이 기존 등록 종목과
   이름을 대조해 자동으로 판단하므로 별도로 표시하지 않는다.
6. 결과는 복사하기 쉽도록 코드 블록 하나로 출력하고, 그 아래에 "설정 → 보유 화면
   텍스트 붙여넣기에 붙여넣어 미리보기에서 확인하라"는 안내를 한 줄로 덧붙인다.
7. 이미지가 흐릿하거나 잘려서 특정 값(수량/현재가/평균단가 중 하나)을 확신할 수 없으면
   그 값을 추측해서 채우지 말고, 어느 종목의 어느 값이 불확실한지 짧게 알려준다.

## 예시 출력

```
삼천당제약 13 170400 453000
소수 0.436057 170400 453000
TIGER KRX금현물 328 13550 13957
비트코인 0.07898433 89952000 122291612
JOBY 51 7.15 10.04
BND 8 100468 101078
1Q 은액티브 77 8975 9615
```
