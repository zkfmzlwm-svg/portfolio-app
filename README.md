# 📱 포트폴리오 앱 (v5.0)

증권사/코인 앱의 보유·거래 내역을 반영하고, 듀얼 스위칭 신호에 따라 자산 비중을
어떻게 높이고 낮출지 판단하는 개인 포트폴리오 트래커입니다.
Android WebView 셸(`MainActivity.java`) + 단일 파일 웹앱(`app/src/main/assets/index.html`) 구조라
서버 없이 동작하고, 모든 데이터는 기기 내부(SharedPreferences)에만 저장됩니다.

## 🚀 APK 빌드

### GitHub Actions (서버/로컬 환경 불필요)
1. 이 리포를 GitHub에 push하면 **Build Portfolio APK** 워크플로가 자동 실행됩니다.
   (수동 실행도 가능: Actions 탭 → Run workflow)
2. 완료 후 Artifacts에서 `portfolio-apk-v{버전}`(예: `portfolio-apk-v5.0`)을 다운로드 → 압축 해제.
3. 정식 서명 키스토어 Secrets(`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`)가
   없어도 **디버그 서명 APK**가 함께 산출되므로 바로 설치할 수 있습니다.
4. 스마트폰에서 `.apk` 실행 → "출처를 알 수 없는 앱" 허용 → 설치.

### 로컬 빌드 (Android Studio 또는 Gradle)
```bash
./gradlew assembleRelease   # JDK 17 + Android SDK 필요
# 결과: app/build/outputs/apk/release/app-release.apk
```
`gradle/wrapper/gradle-wrapper.jar`가 없으면 `gradlew`가 시스템 gradle로 자동 폴백합니다.

### 거래 내역 반영 — 두 가지 방식
1. **개별 거래**: 종목 카드의 ＋매수/－매도 버튼 → 수량·체결단가 입력 시 평균단가가
   가중평균으로 자동 계산되고 거래내역 원장에 기록됩니다. 전량 매도는 실현손익을 남기고
   보유 목록에서 자동 제거됩니다. 워치리스트의 "내 종목으로 이전(매수)"도 동일하게 기록됩니다.
2. **화면 붙여넣기(스냅샷)**: 증권사·업비트 앱의 보유종목 화면을 복사해 설정에서 붙여넣으면
   국내/해외/채권/금/코인 전 종목을 인식하고 **적용 전 미리보기**에서 수량·현재가·평균단가를
   확인·수정할 수 있습니다. 정수/소수 분리 표기, 평가금액·수익률 컬럼 혼재,
   `1Q 은액티브` 같은 숫자 포함 종목명, 쉼표와 %를 모두 견딥니다.
   화면에서 사라진 종목은 전량매도(거래내역 기록) 또는 단순 제거를 선택할 수 있습니다.

> ⚠️ 거래내역의 삭제는 기록만 지우며 보유수량은 되돌리지 않습니다. 보유 잔고는 항상
> 마지막 스냅샷/거래 반영 결과가 기준입니다. 중요 데이터는 설정의 JSON 백업으로 보관하세요.

### 워치리스트 자동 관리 (목표주가 자동조회 + 자체 알고리즘, v5.0)
**앱을 실행할 때마다**(그리고 종목 탭 "↻ 가격 업데이트" 수동 클릭 시) 워치리스트 종목의
**증권사 목표주가 컨센서스도 함께 자동 조회**됩니다(국내·해외 모두 네이버 증권 컨센서스
`consensusInfo.priceTargetMean` 기준 — 야후 quoteSummary는 crumb 인증이 필요해 사용하지 않습니다).
직접 입력한 값은 다음 업데이트 때 조회된 값으로 덮어써집니다.

같은 시점에 **자체 스코어링 알고리즘**이 동작해 "목표주가까지 남은 상승여력"과
"업종 기준 PER 대비 저평가도"를 합산 점수로 계산하고(카드에 `알고리즘 ±점수` 배지로 표시),
- 점수가 높은 순으로 워치리스트를 자동 재정렬하고
- 목표가를 이미 넘어섰고 PER도 고평가로 돌아서 더 지켜볼 실익이 없는 종목은 자동으로 제외합니다.

특정 종목을 계속 관찰하고 싶다면 카드의 **📌 버튼으로 고정**하세요. 고정된 종목은 점수와
무관하게 자동 제외 대상에서 빠집니다. (자동 조회 API는 네이버·야후의 비공개 모바일 API라
필드가 바뀌면 조용히 실패할 수 있으며, 그 경우 값이 갱신되지 않을 뿐 앱이 죽지는 않습니다.)

앱을 며칠씩 안 열면 그동안은 갱신되지 않습니다 — 순수 로컬 WebView 앱이라 백그라운드
스케줄러(WorkManager 등) 없이 "앱을 여는 시점"을 갱신 트리거로 씁니다(`MainActivity`가
WebView 페이지 로드 완료 시 `autoUpdateOnLaunch()`를 자동 호출).

### 업비트 실거래 주문 (선택 기능)
설정 탭에서 업비트 **Open API 키**(자산조회·주문조회·주문하기 권한만, **출금하기 권한은 발급 금지**)를
등록하면 코인 카드의 **⚡ 업비트 실거래 주문** 버튼으로 지정가/시장가 매수·매도 주문을 실제 계좌에
전송할 수 있습니다. JWT 서명(HS256, HMAC-SHA256)은 `MainActivity.java`에서만 처리되어 비밀키가
JS로 노출되지 않으며, 네이티브 HTTP 브릿지를 통해 CORS 없이 `api.upbit.com`과 통신합니다.
주문 체결 후 모달의 **체결 상태 확인 → 포트폴리오 반영** 버튼으로 실제 체결 수량·평균단가를
보유 종목에 반영할 수 있습니다.
- API 키는 기기 로컬(SharedPreferences)에만 저장되며 외부 서버로 전송되지 않습니다.
- 업비트 정책상 주문/출금 권한은 **PC 웹에서만** 발급 가능하고, 주문 기능을 쓰려면 이 앱이
  통신할 공인 IP를 업비트에 등록해야 합니다(모바일 회선은 IP가 자주 바뀌므로 고정 IP 환경 권장).

### 한국투자증권·키움증권 실거래 주문 (선택 기능, 국내주식 현금 매수/매도만 지원)
설정 탭에서 각 증권사의 **App Key/Secret**과(한국투자증권은 **계좌번호 앞 8자리 + 상품코드**도) 등록하면
국내주식 카드의 **⚡ 증권사 실거래 주문** 버튼으로 지정가/시장가 매수·매도 주문을 실제(또는 모의) 계좌에
전송할 수 있습니다. OAuth2 접근토큰 발급·캐시와 요청 서명은 `MainActivity.java`에서만 처리되어 시크릿이
JS로 노출되지 않습니다.
- **한국투자증권**: KIS Developers(apiportal.koreainvestment.com)에서 오픈API 신청 → 앱키/앱시크릿 발급.
  `POST /oauth2/tokenP`로 토큰 발급(24시간 캐시) 후 `POST /uapi/domestic-stock/v1/trading/order-cash`로 주문.
- **키움증권**: 키움 REST API(openapi.kiwoom.com)에서 앱키/시크릿키 발급. `POST /oauth2/token`으로 토큰
  발급 후 `POST /api/dostk/ordr`(api-id: `kt10000`/`kt10001`)로 주문.
- 두 증권사 모두 신용·해외주식은 지원하지 않으며, **실제 체결 여부/체결가는 자동으로 조회하지 않습니다** —
  주문 전송까지만 자동화되고, 체결 확인 후에는 기존 **＋매수/－매도 반영** 버튼으로 직접 기록해야 합니다.
- 두 증권사 모두 **모의투자 환경을 먼저 시도**해볼 것을 권장합니다(설정 탭에서 실전/모의 전환).
- API 키는 기기 로컬에만 저장됩니다. 주문 관련 tr_id/엔드포인트는 각 증권사 공식 GitHub 예제
  (`koreainvestment/open-trading-api`, `Kiwoom-Securities/Kiwoom-REST-API`) 기준으로 구현했습니다.
